# 访谈提纲生成器 - 现状说明（供AI审查）

## 一、系统概述

这是一个用于生成汽车市场调研访谈提纲的Web应用，支持多国对比研究。核心功能是根据研究类型、国家、模块选择动态生成结构化的访谈大纲。

**部署地址**: https://theleapunion.com/internal/interview-outline/

**技术栈**: 纯前端HTML/JS/CSS，无后端依赖，数据硬编码在JS文件中

### 3.2 模块结构示例

#### FGD座谈会（7个模块）

1. **人群画像** (f1) - 基本信息、心理画像与小车定义、购车背景与生活方式
2. **使用场景** (f2) - 日常用车场景、座舱功能使用、里程路况、使用成本
3. **当地气候路况下的特定场景** (f2b) - 高温/雨季气候适配、空调体验、停车与路况
4. **使用满意度，痛点/痒点** (f3) - Dealer服务满意度、车辆满意/不满意、痛点参考表、维修保养
5. **购车考虑因素** (f4) - 购车决策回顾、备选对比、决策时间线、金融方案与租赁接受度
6. **产品评价** (f5) - 竞品评价、造型/CMF风格测试、续航充电、智能座舱、智驾、价格、安全
7. **品牌形象** (f6) - 国别品牌偏好、中国品牌认知与印象、一句话概括

#### IHV入户访谈（3个模块）

1. **家庭背景** (i2) - 车辆历史、补贴/动力选择背景、驾驶分工、里程路况、满载出行
2. **购买旅程** (i3) - 购车时间轴与决策基石、信息触点与备选漏斗、试驾验证、动力形式评估、最终决断与权衡、金融方案、使用满意度
3. **看车流程** (i4) - 停车环境勘探、后备箱装载、座舱硬件实测、充电设施/加油习惯勘察、配置与五大卖点测试、结语

#### Dealer经销商访谈（9个模块）

1. **自我介绍** (d1) - 开场白与保密承诺、经销商与企业背景自我介绍
2. **该品牌发展状况** (d2) - 品牌格局TOP5、新进入者、竞品优劣势、品牌鄙视链、版型与成交价
3. **当地政策/补贴等** (d3) - 税收优惠/补贴政策内容与影响、充电基础设施现状
4. **目标category销量预测** (d4) - 年销量规模与占比、细分市场规模、未来3年趋势、新能源渗透与动力偏好
5. **用户画像** (d5) - 典型客户画像、家用/营运构成、购买触发、决策周期
6. **购车动机/顾虑** (d6) - TOP3决策因素、女性决策、一票否决、新能源顾虑、智能化与保值率
7. **产品优势/推销/售后服务** (d7) - 渠道触点与社交媒体、定价与版型策略、渠道与售后建议、营销与上市建议
8. **客户关键卖点测试** (d8) - 色彩偏好、五大卖点测试、配置买单与溢价、安全认证、核心卖点与传播语
9. **中国品牌pros and cons** (d9) - 中国品牌发展现状、机会与挑战、信任度与技术卖点

## 四、题目内容特点

### 4.1 题目结构

每道题目采用HTML格式存储，包含以下元素：

- **主问题**: `<li>`标签，如"请您简单介绍一下自己，比如年龄、职业，还有家里有哪些家庭成员？"
- **追问/主持人注意**: `<div class="probe">`标签，如"【主持人注意/追问：是否有子女，年龄；是否与老人同住？】"
- **分支逻辑**: `<div class="branch">`标签，按BEV/ICE车主分组提问
- **子标题**: `<h5>`标签，用于模块内部分节

### 4.2 动态替换机制

题目中的硬编码内容会在生成时动态替换：

- **国家/城市**: `{city}` → 实际城市名（如"圣保罗"）
- **对标车型**: 根据用户输入的对标车型替换
- **产品卖点**: 替换为`state.sellingPoints`中的内容
- **配置项**: 替换为`state.configItems`中的内容
- **气候/路况条件**: 根据`state.conds`注入条件标签

### 4.3 条件过滤系统

通过`COND_RULES`定义条件过滤逻辑，例如：

- 选择"BEV车主"→ 仅显示BEV相关题目
- 选择"热带气候"→ 显示高温/雨季相关题目
- 选择"充电不便"→ 显示充电设施相关题目

## 六、待审查重点

### 6.1 内容准确性

1. **对标车型是否过时**: 题目中硬编码的对标车型（如BYD Dolphin Mini、Geely Geometry EX2等）是否需要更新？
2. **政策信息是否准确**: 各国税收政策、充电基础设施描述是否反映当前状况？
3. **市场描述是否过时**: 品牌格局、竞品分析是否需要同步最新市场动态？

### 6.2 逻辑一致性

1. **BEV/ICE分支是否完整**: 所有涉及动力类型的分支是否都覆盖了BEV和ICE两种情况？
2. **追问是否匹配主问题**: `<div class="probe">`中的追问是否与主问题逻辑一致？
3. **模块间是否有重复**: 不同模块是否存在题目重复或冲突？

### 6.3 通用性

1. **国家替换是否充分**: 除了BR/IT/ID/HK/TH外，其他国家使用时是否需要额外本地化？
2. **车型替换是否完整**: 所有硬编码的车型描述是否都能被动态替换？
3. **行业术语是否统一**: "4米纯电小车"、"小型车"、"紧凑型车"等表述是否一致？

### 6.4 缺失内容

1. **上市前测试阶段**: 该阶段提纲完全缺失，是否需要补充？
2. **上市后检验阶段**: 该阶段提纲完全缺失，是否需要补充？
3. **非汽车行业的通用性**: 当前系统是否只能用于汽车调研？

```javascript
const state = {

  modOrder: [],             // 模块排序

  repCountries: {},         // 各国对标车型

  segment: '',              // 车型级别
  bodyType: '',             // 车身类型
  personnel: 'middle',      // 人员分类
  conds: {                  // 研究条件
    climate: '',            // 气候
    roads: '',              // 路况
    charging: '',           // 充电
    power: [],              // 动力类型
    drive: '',              // 驱动方式
    incentive: '',          // 激励政策
    finance: '',            // 金融方案
    usage: ''               // 使用场景
  },
  viewMode: 'outline',      // 视图模式（outline/tree）
  bevBench: '',             // BEV对标车型
  iceBench: '',             // ICE对标车型
  otherBench: '',           // 其他对标车型
  f5Subs: {},               // F5子模块选中状态
  subs: {},                 // 通用子模块选中状态
  sellingPoints: [],        // 产品卖点
  configItems: []           // 配置项

```

### 7.3 生成流程

1. 用户选择研究类型（如FGD）
2. 选择国家（如BR, IT, ID）
3. 选择模块（如f1, f2, f5）
4. 填写对标车型、产品卖点、配置项
5. 设置研究条件（气候、路况、动力类型等）
6. 点击"生成提纲"
7. 系统从`DATA[type].countries[cc].mods[modId]`提取HTML
8. 通过`injectConds()`注入条件标签
9. 通过`applyReplacements()`替换车型/卖点/配置
10. 渲染为结构化提纲

## 八、已知问题与修复历史

### 8.1 已修复的P1问题（2026-09-30）

1. **switchStage()状态残留**: 切换研究阶段时未清空countries/f5Subs/subs等字段
2. **countryCount不恢复**: 切换类型后countryCount不会恢复到用户期望值（通过`_desiredCc`字段解决）
3. **collectSelectedCountries()空值崩溃**: 未检查`state.type`和`DATA[state.type]`是否存在
4. **render()空值崩溃**: 未检查`DATA[state.type]`是否存在
5. **moveQuestion()视图模式判断**: 议题树模式下不应允许移动题目
6. **updateProductData()丢弃空白行**: 过滤掉了空的卖点行，导致编辑后丢失

### 8.2 待优化的P2问题

1. 模块拖拽排序在移动端体验不佳
2. 议题树视图不支持编辑模式
3. PPT生成功能尚未完善
4. Excel导出未支持多国对比
5. 缺少提纲版本管理功能

## 九、审查建议

请重点审查以下内容：

1. **题目内容的专业性**: 是否符合汽车市场调研的行业标准？
2. **问题设计的科学性**: 是否避免了引导性问题？是否覆盖了关键维度？
3. **跨国文化敏感性**: 各国版本是否考虑了文化差异？

5. **模块划分的合理性**: 模块间的逻辑边界是否清晰？
6. **追问设计的有效性**: 追问是否能有效引导深入讨论？

## 十、2026-09-30 题库与角色结构更新
