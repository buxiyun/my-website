# 访谈提纲系统材料索引

本目录保存题库审定、系统生成和后续交接所需的材料。网站运行文件仍位于上一级目录。

## 可直接审阅的材料

- `题库审定/汽车访谈题库_2C与2B分角色修订版.xlsx`：本轮审定后的题库总表，包含 2C、2B、角色问法、追问与触发条件。
- `题库审定/原始_访谈提纲模块问题汇总-2.xlsx`：本轮整理前的原始题目汇总，作为来源对照。

## 系统生成材料

- `题库审定/题库审定数据.json`：生成系统题库所使用的结构化审定数据。
- `题库审定/生成bank-v3.mjs`：把审定数据转换为 `js/data/bank-v3.js` 的生成脚本。
- `../js/data/bank-v3.js`：网站实际读取的新版题库，共 192 张归并题卡。

## 页面入口

- `../index.html`：模块化开发版入口。
- `../index.bundle.html`：已经内嵌样式、脚本和题库的离线单文件版本。
- `../系统现状说明.md`：系统结构、当前能力和交接说明。

## 当前访谈类型

- 2C：FGD 座谈会、IHV 入户访谈。
- 2B：Dealer 经销商、汽车媒体、主机厂专家、商务／组织采购者。

推荐模块默认选中，按需模块默认不选；正文会根据访谈角色调用对应问法，并显示题目的适用或触发条件。
