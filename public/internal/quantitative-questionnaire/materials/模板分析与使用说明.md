# 汽车定量问卷生成器

## 使用

双击上一级目录的 `index.html` 即可使用。该文件包含全部题库、样式和程序，无需安装或连接网络。修改开发源文件后，在此目录执行 `node build.cjs` 可重建。

1. 选择通用汽车、小型纯电车、高端MPV起始模板，填写项目名称和品类。
2. 选择现有车主／购车意向者、市场，设置币种、配额、收入档位与筛选参数。
3. 展开模块，勾选题目。自动保留其他已选题的前置题。可编辑题干、选项编码、矩阵行、数量限制、显示条件及所属模块，也可新增题目。
4. 设置材料与方案：配置、竞争方案、颜色、特点及图片版本说明。涉及价格的材料分别填写各市场当地版本。
5. 查看逻辑检查，再生成问卷。每个市场分别输出，车主与意向者差异问法明确标注。
6. 导出Word兼容格式审阅稿（.doc）、题目清单CSV或项目JSON。JSON可再次载入；CSV可用Excel查看。Word导出并非DOCX。

此工具输出问卷设计和编程说明稿，未执行受访者跳题、配额拦截、随机分组或数据采集。显示条件由编程人员实施。材料填写的是名称、版本和说明，不会将原模板中的图片自动提取并插入。

## 两个参考模板

### S11消费者定量

来源：用户提供的《中文问卷--S11_定量问卷_0717 Final-Clean version.xlsx》。主问卷629行，并含不满、品牌、关注因素、渠道、兴趣、价值观和产品配置等辅助表。

结构：筛选资格 → 家庭车辆／购买属性 → 购车因素和渠道 → 场景和使用体验 → 动力与家充 → 配置排序（仅配置／加入价格／加入品牌）→ 卖点、续航、单项配置提供与不提供评价／付费 → 人口背景。

可复用机制：大类及细项父子关系、选项带入、场景循环、稳定方案代码、市场币种替换、量表方向、互斥项、排序唯一性、条件显示。

### 高端MPV海外定量

来源：用户提供的《高端MPV海外定量问卷_EZQ0507-llink test comment.rtf》。包含香港和泰国筛选，以及车主／意向者差异问法。

结构：同意与筛选 → 家庭及车辆 → 高频与重要场景 → 里程与第二／第三排使用 → 外观各部位偏好 → 内饰／氛围／屏幕与按键 → 配置期待、版本数量和升级溢价。

可复用机制：实际使用和未来预期分开、不同座位逐排测量、同一造型多维评价、逐个升级版支付意愿、当地价格与材料版本。

## 第一版题库

84题，10个模块。每题保留原始题号来源；归纳或新增的问法明确标注改编关系。不是两个问卷的逐字完整复刻。

- 筛选与配额
- 家庭与车辆
- 购车决策
- 用车场景与体验
- 动力与补能
- MPV座位与空间
- 概念与竞争方案
- 外观与内饰
- 配置与付费
- 人口与生活背景

核心／可选表示起始选题建议，不能代替研究目标判断。访问时长为题型及循环数量的粗估，应试访问确认。

## 没有沿用的项目专属或有疑问内容

- 固定市场配额、历史购车日期、指定车型名单、收入门槛、各币种价格和汇率：转为项目设置，不自动沿用。
- S11 D5a的0—1000公里月里程硬上限：取消；异常值应确认。
- S11 X21／X22的强制矛盾拦截：不沿用。喜欢某配置并接受不提供，可以同时成立。
- S11 X3a中的排序引用：改为比较加入价格与加入品牌两轮，引用C5与C6。
- MPV Q70中“均优于”竞品的预设：不迁移，以已核验配置与价格材料评价。
- 造型“喜欢”与“愿意购买”合为一问：拆开，避免把设计偏好等同购买倾向。
- MPV文件内的测试备注、待修改意见、题号重复：作为来源说明参考，不当成已经定稿的访问指令。
- 材质题统一评价座椅面料，不让座椅材料与木纹、金属装饰面竞争。
- 量表列保持原序；只有配置行或选项按题目要求随机，其他／互斥项置底。

## 检查边界

可检查：选择题选项、选项编码重复／空值、数量上下限、数值范围、矩阵行、前置题缺失／顺序、市场收入档位、配额总数、材料待办、粗估时长。

仍需人工确认：筛选样本定义、车辆资格及使用者门槛、条件表达、城市和车型名单、翻译、量表跨市场一致性、材料真实性、真正受访者程序与试访问。

原始模板没有被修改，也没有复制原文件到本项目目录。项目内只保留改编题库及来源题号。
